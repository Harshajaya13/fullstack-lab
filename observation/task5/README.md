# Project-Based Learning (PBL) - Task 5

This directory contains solutions for **Observation Task 5**, covering CO-1 and CO-2 modules.

---

## File Overview

| File | Description | Technology |
|---|---|---|
| `q1_calculator.html` | Interactive Product Calculator calculating total price dynamically. | HTML5, CSS3, Vanilla JS |
| `q2_file_manager.js` | Interactive file manager creating, reading, appending, and reading files. | Node.js (`fs`, `readline`) |
| `q3_server.js` | Express.js REST server serving `/`, `/students`, and `/about`. | Node.js, Express.js |
| `q4_dom_demo.html` | Comprehensive DOM explanation with dynamic content, style & attribute manipulation. | HTML5, CSS3, JS (DOM) |
| `index.html` | Central task dashboard linking all solutions. | HTML5, CSS3 |

---

## How to Run Each Solution

### 1. Question 1: Product Calculator
Open `q1_calculator.html` directly in any web browser.

---

### 2. Question 2: Node.js File Manager
Run the script using Node.js from the terminal:
```bash
node q2_file_manager.js
```
Follow the on-screen interactive prompts.

---

### 3. Question 3: Express.js Student Server
First install Express dependencies, then start the server:
```bash
npm install
node q3_server.js
```
Open your browser or Postman and test the routes:
- `http://localhost:3000/`
- `http://localhost:3000/students`
- `http://localhost:3000/about`

---

### 4. Question 4: DOM Explanation & Live Demo
Open `q4_dom_demo.html` directly in any web browser to view theory and test interactive buttons.
