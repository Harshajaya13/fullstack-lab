JavaScript Functions vs Classes

1. Key Differences

Feature Functions Classes (ES6)
Primary Purpose Used to execute a block of code or perform a calculation. Used as a blueprint to create multiple objects.
Syntax function add(a, b) { ... } class Student { constructor() { ... } }
Hoisting Function declarations are hoisted (can be called before definition). Classes are NOT hoisted (must be declared before use).
Object Creation Returns a single value or object. Instantiated using the new keyword to create objects.

2. How Classes Create Multiple Objects

A class defines common properties (inside constructor()) and methods (functions attached to the class). Using the new keyword, we can instantiate multiple unique objects that share the same behavior.
